- Plages, défauts et listes de modèles sont publiés par l'API (`GET /api/parameters`) ; l'interface n'en écrit aucune.
- R23 : `GET /api/engine/node-tree?controls=true` permet de comparer l'API aux contrôles de scsynth par l'API seule.
- R24 : une commande sclang de plus de 4 096 octets passe par un fichier `.scd` chargé ; toute commande se termine par `nil`.
- Le banc EQ figure dans le catalogue (`bench.eq`) pour que l'interface n'écrive pas ses plages.
- L'interface ne pilote pas la souris du poste : l'option `--capture` enregistre les onglets pour la vérification visuelle.

## Pour reprendre

1. Ouvrir le worktree `grrzzzz/.worktrees/sc-engine-generic`.
2. `cd mixette-SCEngine/engine && npm test` (251 tests attendus).
3. `cd mixette-SCEngine/desktop && cmake --preset mingw && cmake --build build/mingw && ctest --preset mingw`.
4. Essai manuel : `engine\engine.cmd start`, `desktop\start-desktop.cmd`, démarrer le moteur dans l'onglet Moteur.
5. Restent : la tâche 8d (moteur), la tâche 9 (installateur), la revue finale, puis la fusion.
